SC2 UI 工作台 · 第一次使用

1. 双击本文件夹里的「启动SC2 UI 工作台.exe」。
2. 第一次会弹出文件夹选择框：选择以 -UI-Test 结尾的测试地图副本（例如 黄金矿工-UI-Test.SC2Map，里面要有 ComponentList.SC2Components）。之后会自动记住这个路径。
3. 浏览器会自动打开 http://127.0.0.1:8765/。在页面里从「项目管理 → 打开项目 JSON」载入你的项目。
4. 点「实机预览 → 写入并测试」，游戏会自动启动。
5. 关闭工作台的浏览器标签页（或整个浏览器）。本地服务会在几秒内自动退出并释放端口；如果浏览器异常退出，最多两分钟兜底。exe 本身没有窗口、控制台或托盘，浏览器就是唯一界面。

说明：
- 直接双击 index.html 仍可编辑和导出，但不会显示「写入 / 启动」按钮；浏览器不允许网页直接启动本地游戏程序。
- 如果工作台已经在运行，再次双击 exe 会直接打开已有页面，不会重复启动。
- 测试副本路径保存在 %LOCALAPPDATA%\SC2WorkbenchPreview\map.txt；换地图时删除这个文件，下次启动会重新选择。
- 预览只负责显示布局和贴图，不接入触发器、事件、动作函数或 GUI 变量；响应逻辑由你或本地 agent 另外接入。
