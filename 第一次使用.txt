SC2 UI 工作台 · 第一次使用

1. 双击本文件夹里的「启动SC2 UI 工作台.exe」。
2. 浏览器会自动打开 http://127.0.0.1:8765/。在页面里从「项目管理 → 打开项目 JSON」载入你的项目。
3. 打开「实机预览」。首次没有目标时，展开「更换测试副本」，粘贴以 -UI-Test 结尾的测试地图副本完整路径（例如 C:\Users\你\Documents\StarCraft II\Maps\黄金矿工-UI-Test.SC2Map，里面要有 ComponentList.SC2Components），点「确认切换测试副本」。之后会自动记住这个路径；换地图从同一入口切换。
4. 核对「实际写入的测试副本」，勾选写入确认，再点「写入并测试」，游戏会自动启动。
5. 需要把变量真正写进地图时，打开「项目 → 回导地图」。选择目标组件地图和「回导界面和变量」或「仅同步全局变量」，点「生成地图副本」并选择保存目录。生成的是新副本，不修改原地图；用银河编辑器打开副本里的 ComponentList.SC2Components 并保存一次，按 F6 查看变量。
6. 关闭工作台的浏览器标签页（或整个浏览器）。本地服务会在几秒内自动退出并释放端口；如果浏览器异常退出，最多两分钟兜底。exe 本身没有窗口、控制台或托盘，浏览器就是唯一界面。

说明：
- 直接双击 index.html 仍可编辑和导出，但不会显示「写入 / 启动」按钮；浏览器不允许网页直接启动本地游戏程序。
- 如果工作台已经在运行，再次双击 exe 会直接打开已有页面，不会重复启动。
- 测试副本路径保存在 %LOCALAPPDATA%\SC2WorkbenchPreview\map.txt；网页切换后会自动更新。不要手工改这个文件来绕过页面上的目标确认。
- 写入冲突会在页面列出实际冲突文件和 stage-report.json 路径；不会覆盖未确认的原文件。
- 无窗口启动器出错时，日志写在 %LOCALAPPDATA%\SC2WorkbenchPreview\launcher.log。
- 需要让本地 Agent 与你共用画布、批量修改并走定稿回导时，阅读 `Agent协作说明.md`，在工作台目录运行 `node agent.mjs start`；普通实机预览仍双击启动器即可。
- 预览只负责显示布局和贴图，不接入触发器、事件、动作函数或 GUI 变量；响应逻辑由你或本地 agent 另外接入。
