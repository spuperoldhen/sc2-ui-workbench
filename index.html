从工作台到银河编辑器

做一个开局出现、点击后会更新文字的对话框。

在工作台搭好练习界面

添加一个文本和一个按钮，把它们拖开放置。文本写「等待点击」，按钮写「点我」。接着依次选中最外层对话框、文本和按钮，到右侧「绑定」填写变量 ID。

图层变量 ID变量类型
最外层对话框gv_TutorialDialog对话框
文本「等待点击」gv_TutorialStatus对话框项
按钮「点我」gv_TutorialButton对话框项

选中最外层对话框，把「绑定」里的 Galaxy 前缀设为 TutorialUI。在「运行」开启「创建后显示」，玩家范围选「所有玩家」。按钮的「运行」里开启「初始可交互」。

点击「导出 Galaxy」，先检查是否有错误。后续依次会用到「GUI 变量清单」「自定义脚本」「初始化动作」三个页签。

在银河编辑器建立全局变量

打开一张测试地图，按 F6 打开触发器编辑器。在左侧触发器树里右键，选「新建 → 新建变量（New Variable）」。对照工作台的「2 · GUI 变量清单」创建三个全局变量。

  1. 显示名称可用中文，例如「教程按钮」。类型按清单选「对话框」或「对话框项」。本例初始值保持默认。
  2. 点击清单中的变量名，复制 TutorialButton。在编辑器中取消「基于名称（Based on Name）」，把名称粘进可编辑的脚本标识符栏。打开「查看脚本（View Script）」，确认完整识别符为 gv_TutorialButton。
  3. 如果地图里已有可复用的全局变量，把「查看脚本」中的实际标识符填回工作台，再重新导出。

显示名称方便你在 GUI 里选择，脚本标识符供生成的初始化代码使用。

把完整脚本放进左侧触发器树

在银河编辑器的左侧触发器树右键，选「新建 → 新建自定义脚本（New Custom Script）」，命名为「教程 UI 布局」。

  1. 回到工作台，打开「导出 Galaxy → 1 · 自定义脚本」，点「复制脚本」。
  2. 粘贴到银河编辑器右侧的大文本框。「初始化函数（可选）」留空，下一步会从触发器调用。

「新建自定义脚本」建在左侧树。下一步的「自定义脚本」建在右侧动作列表。两个位置各放一段。

开局执行一次初始化动作

在左侧树新建普通触发器「初始化教程 UI」。在右侧添加「地图初始化（Map Initialization）」事件，再在「动作」下添加「自定义脚本（Custom Script）」动作。

在工作台打开「3 · 初始化动作」，点「复制初始化动作」，把你实际导出的内容完整粘进去。本例先加文本、再加按钮时，会看到类似下面的四行。

TutorialUI_Create(PlayerGroupAll());
gv_TutorialDialog = TutorialUI_Dialog;
gv_TutorialStatus = TutorialUI_Label_1;
gv_TutorialButton = TutorialUI_Button_2;

第一行创建界面，后三行把窗口、文字和按钮存到全局变量里。用「测试文件（Test Document）」进地图，先确认能看到窗口和两个控件。

用 GUI 判断点击并更新文字

再新建一个普通触发器，命名为「教程按钮被点击」。下面三项都在触发器 GUI 里选择。

  1. 事件搜索 Dialog Item Is Used。选任意对话框项、任意玩家，事件类型为「点击（Clicked）」。
  2. 条件添加「比较（Comparison）」。左边选函数「被使用的对话框项（Used Dialog Item）」，右边切到「变量」，选「教程按钮」。
  3. 动作搜索 Set Dialog Item Text。对话框项选「教程状态文字」，文字填「你点了按钮！」。玩家组选「将玩家转换为玩家组（Convert Player To Player Group）」，里面的玩家选「触发玩家（Triggering Player）」。

测试成功后，迁移到自己的地图

开局看到「等待点击」，点「点我」后看到「你点了按钮！」，就完成了布局创建、变量绑定和 GUI 调用。

换成实际玩法

  • 游戏投票。6 个按钮可绑定 gv_VoteButtons[1] 至 gv_VoteButtons[6]。在银河建一个「对话框项」数组，覆盖索引 0–6，共 7 个元素。把票数文字更新给投票玩家组。
  • 三选一抽取。开局创建对话框时关闭「创建后显示」。抽取发生时，用 GUI 更新目标玩家的选项，再对该玩家显示对话框。
  • 地图素材。已有字体样式可用同名 ID，例如 TIPS。新增贴图或字体从银河的导入管理器放进地图，路径与工作台填写的路径保持一致。

从现有 GUI 布局开始

在银河「查看脚本」复制创建界面的触发器函数。从工作台「项目 → 导入银河 GUI 布局」粘贴并分析，核对识别结果后打开布局。如果对话框和全局变量在另一段初始化动作里关联，可以一起粘贴到选填区。

修改布局后，替换原来的完整脚本和初始化动作。保持变量绑定一致，原有的 GUI 点击触发器就能继续使用。

导入 SC2Components

选择银河编辑器另存为组件后的地图根文件夹。工作台会列出创建 UI 的 GUI 函数、语言、字体样式和本地素材。

        导出 Galaxy 脚本

        1. 在触发器树新建全局变量，按清单选择类型和数组尺寸。关闭「基于名称」，粘贴复制的名称。将鼠标移到工作台的名称上可查看完整标识符，再用编辑器的「查看脚本」核对。
        2. 将「初始化动作」粘贴到地图初始化触发器中的「自定义脚本」动作。在它后面用 GUI 的设置文本、设置当前值、设置可见性等动作访问这些变量。
        3. 按钮事件使用「任意对话框项被使用 · 点击」，条件使用「被使用的对话框项 ＝ 变量或数组元素」。用「触发玩家」记录本次投票或选择。列表、复选框等按实际用法选择对应事件类型。

        观战 HUD 的 GUI 接法

          从银河编辑器「查看脚本」复制全局变量声明，或打开本地的 MapScript.galaxy。核对在本机完成。

          游戏内运行报错怎么排查
          • 「无效参数列表」先核对调用的变量名与类型，例如 gv_VoteUI_Voters 应为玩家组，再确认完整脚本里的创建函数与初始化调用相符。
          • 「没有有效的宽度或高度」用同一版本导出完整脚本与初始化动作，替换后测试。铺满父容器的控件也会先写入正宽高。
          • 布局创建成功但窗口没显示时，核对对话框的初始可见性及玩家组成员。先用当前测试席位验收，再加入其他玩家。
          • 外观差异先看「资源清单」，确认地图导入路径、依赖和字体样式。可用参考截图的分屏对照定位边界。
